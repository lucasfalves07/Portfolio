## 🛠️ Tecnologias

## 🚀 Como rodar

Sem instalação necessária. Basta clonar o repositório e abrir o arquivo no navegador:

```bash
git clone https://github.com/lucasfalves07/portfolio.git
```

Em seguida, abra o arquivo `index.html` diretamente no seu navegador.

## 📁 Estrutura

```
portfolio/
└── index.html   # Todo o HTML, CSS e JS em um único arquivo
```
